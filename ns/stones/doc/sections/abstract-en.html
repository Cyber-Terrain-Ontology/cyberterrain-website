Abstract

STONES (STIX ONtology Expression System) is an OWL 2 binding of the OASIS STIX 2.1 specification. It gives STIX Domain Objects, Cyber Observable Objects, Relationship Objects, Meta Objects and structured sub-types a formal class hierarchy, provides datatype and object properties for the standard STIX properties, and represents STIX's open and controlled vocabularies as SKOS concepts, so STIX data can be queried with SPARQL and reasoned over with OWL.
