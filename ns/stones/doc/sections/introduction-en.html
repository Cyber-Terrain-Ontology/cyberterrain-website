Introduction back to ToC

STONES is an OWL 2 ontology modelling the OASIS STIX 2.1 specification. It provides a complete class hierarchy for all STIX Domain Objects, Cyber Observable Objects, Relationship Objects, Meta Objects, and structured sub-types, together with the datatype and object properties covering every standard STIX 2.1 property. Within the CyberTerrain ecosystem, STONES is maintained as a framework ontology — an independently versioned, authoritative reference vocabulary for STIX 2.1, in the same role that CWE, CAPEC, and CVE play for their own domains. STONEWORK, the ground-truth ontology for cyber threat intelligence in CyberTerrain, aligns with STONES as a peer reference rather than importing and extending it. Every STIX domain object, observable, and relationship modeled here preserves the semantics of STIX 2.1 exactly — nothing is reinterpreted. What changes is the representation: STIX 2.1's JSON exchange format becomes formal, queryable OWL structure, suited to SPARQL queries, OWL reasoning, and integration into knowledge graphs and AI-driven analysis pipelines. STONES is independent work and is not affiliated with OASIS or the OASIS Cyber Threat Intelligence Technical Committee (CTI-TC), which develops and maintains the STIX 2.1 standard.
